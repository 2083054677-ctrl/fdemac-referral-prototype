# FDE 共学营原站复刻＋拉新支线原型

这版以用户提供的「FDE 共学营第一期丨观猹」完整网页存档为底稿，保留原站导航、左侧课程目录、中间正文、右侧报名与学习群结构，仅在课程正文中加入拉新裂变支线。

## 查看方式

建议在本目录启动静态服务器：

```bash
python3 -m http.server 4181
```

随后访问 `http://127.0.0.1:4181/`。

## 新增内容

- Plan A：删除原“学完能获得”长列表，让课程主线直接衔接邀请支线
- 精简为“邀请好友共学”，移除重复的数据概览和海报说明
- 「课程支线 · 共学同行计划」入口与说明
- 专属邀请链接、复制链接与生成海报
- 1 / 5 / 10 / 15 人非等距任务轨道与奖励徽章
- 邀请人数、当前排名、下一档提示联动
- 绿色窄版瓜棚轮播与一键跳转入口
- 瓜棚实物轮播：角色徽章、限定背包、角色卫衣
- 排行榜改为上方奖品、下方完整 Top 10 榜单
- 榜单展示完整昵称与人物头像，不再使用姓名缩写
- 移除总预算文案，奖品区改为浅绿、米白和暖灰
- Mac mini 头奖与观猹抱奖品角色插画
- 活动规则、瓜棚入口与演示状态

## 文件说明

- `index.html`：用户提供的原页面存档，仅增加扩展样式和脚本引用
- `fdemac-extension.css`：新增支线模块样式
- `fdemac-extension.js`：新增模块结构与原型交互
- `FDE 共学营第一期丨观猹_files/`：原页面本地资源
- `assets/`：新增奖品图片资源

排行榜和邀请数据均为原型演示数据，正式开发时需接入邀请归因、Admin 活动配置、奖励发放与榜单核验接口。
