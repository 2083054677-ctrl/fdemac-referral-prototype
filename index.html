FDE 共学营

FDE 共学营第一期

会调用模型的人越来越多，但能把 AI 真正落到业务“最后一公里”的人，依然稀缺

观猹「FDE 实战共学营」就是来培养这样的人才：一个为期 8 天的企业 Agent 实战计划，带你从需求拆解、技术选型、原型开发，到部署上线、效果评估和业务交付，打通 AI 落地的完整链路。 最终交付一套：能运行、能解决问题、能持续迭代的 AI 系统。

本期已结营，你仍可继续学习和提交作业；结营后提交不再批改，也不参与结营评审与奖励。

关于活动

  • 一线企业实战型 FDE 共学营，从真实业务场景出发，完整跑通企业 Agent 的交付链路
  • 业务需求挖掘 → 项目范围界定 → CLI 开发原型 → Skills 封装 → 企业系统接入 → Evals 评测 → 生产部署与项目路演
  • 每天围绕一个关键交付环节展开，由讲师讲解方法、工具与实战经验，学员使用免费的企业级平台完成一个真实业务场景项目
  • 结营时，你将交付一个可运行、可评测、可展示的企业 Agent 项目，而不只是一个概念 Demo

课程主线 · 从业务命题到企业级 Agent 交付

前 5 天连续打卡学习，每晚 7 点直播 + 作业提交，围绕真实企业业务命题，依次完成需求挖掘、范围界定、Agent 原型开发、Skills 工程、企业系统接入与生产评测。 第 6—7 天为完成结课作业时间，同时我们提供求职与作品集选修课程，有 FDE 求职、转岗或创业需求的同学可按需参与； 第 8 天完成优秀项目展示与结营 Demo Day。

1

了解FDE全局

FDE 工作全流程；理解企业 Agent 不是独立应用；梳理业务人员、流程、数据与内部系统；梳理企业知识库

2

项目范围界定＋CLI 开发工作流＋首个原型

明确项目边界和量化指标；使用 Claude Code、Codex CLI、Cursor 等完成原型；理解 CLI 如何参与企业开发和系统操作

3

Skills 工程＋上下文工程

将业务经验、操作流程和判断标准沉淀为 Skills

4

企业系统接入：MCP、API 与 CLI

Agent 连接 CRM、知识库、数据库、工单等内部系统

5

Evals＋从 Demo 到企业生产

企业 Agent 评测体系；准确性、任务完成率、权限与异常处理；Skills 迭代；接入企业级平台

6

FDE 求职冲刺（选修）

FDE 岗位画像、简历写法、作品集搭建、面试方式、创业与交付路径

7

结营＋优秀项目 Demo Day

完整项目展示、业务价值说明、技术方案与现场答辩

覆盖 Claude Code、Codex CLI、Cursor、MCP、API、Skills、企业知识库、数据库与业务系统接入，以及身份认证、权限控制、日志监控、Evals 和企业级 Agent 部署方法。

学完能获得

  • 完整理解 FDE 的岗位职责、工作流程与能力模型
  • 掌握企业需求挖掘、项目范围界定和业务流程梳理方法
  • 使用 Claude Code、Codex CLI、Cursor 等工具开发企业 Agent
  • 将业务 SOP、专家经验与判断标准封装为可复用 Skills
  • 完成 Agent 与 CRM、知识库、数据库、工单等企业系统的连接
  • 建立准确性、任务完成率、权限与异常处理等 Evals 评测体系
  • 完成一套企业级项目作品集：GitHub、项目文档、架构图、Demo 与 Eval 报告
  • 优秀项目获得 Demo Day 路演与后续求职、作品集展示机会
